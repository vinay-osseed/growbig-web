# Site Platform Content

## Purpose

Site Platform Content owns reusable content blocks that are not tied to one page.

Examples:

- footer CTA
- announcement bar
- office/contact block
- global intro text
- reusable partner/support block

A Site Content Block belongs to one Site Profile and is exposed through stable source/key values.

## Content Types

This module adds:

- Site Content Block

## Current Scope

This is the first reusable content foundation.

It supports:

- site-scoped reusable content
- source grouping
- stable content keys
- API output

Later phases can add:

- media fields
- content block components
- scheduled publishing
- richer field types
- shared/global cross-site content
