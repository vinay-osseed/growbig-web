# Site Platform Component

## Purpose

Site Platform Component owns the first component model for API-driven pages.

Components are implemented with Paragraphs for this phase.

## Paragraph Types

This module adds:

- Site Hero
- Site Rich Text
- Site CTA

## Page Field

This module adds this field to Site Page:

    field_page_components

The field references Paragraph components in ordered form.

## Current Scope

This is the first component foundation.

It supports simple normalized JSON output through the page API.

Later phases can add:

- media/image fields
- reusable components
- component preview
- component library documentation
- advanced frontend schema validation
