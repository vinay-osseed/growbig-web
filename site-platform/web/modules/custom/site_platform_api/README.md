# Site Platform API

This module exposes normalized frontend-ready JSON responses under `/api/v1`.

## Endpoints

- `/api/v1/site`
- `/api/v1/pages/{slug}`

## Current examples

- `/api/v1/site`
- `/api/v1/pages/home`
- `/api/v1/pages/about`

## Purpose

The API hides raw Drupal entity structures and returns clean JSON for the decoupled frontend application.
