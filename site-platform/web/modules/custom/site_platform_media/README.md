# Site Platform Media

Site Platform Media owns reusable site-scoped media asset records.

This phase intentionally stores media metadata and URL references only.

It supports:

- stable media key
- media kind
- media URL/reference
- alt text
- credit
- active flag
- site scoping
- setup YAML import
- public media API output

Later phases can add real binary file import, image styles, remote download, asset replacement, and CDN integration.
