# GrowBig UI Reference

## Purpose

This document captures the GrowBig mockup direction as one implementation of Site Platform.

GrowBig is not the platform itself.

GrowBig is one site profile that uses the shared platform codebase.

## Observed UI Sections

The mockup includes:

- clean white header
- GrowBig logo
- top navigation
- Get Started CTA
- dark hero section
- large headline with blue highlight text
- phone/device mockup
- hero CTA buttons
- stats counters
- services card section
- partner/logo strip
- footer with company info, quick links, services, contact info
- about mission and vision cards
- values cards
- leadership/team card grid
- careers hero
- careers stats
- job filter tabs
- open role cards
- careers CTA
- contact form
- contact info card
- social links

## Backend Component Mapping

| UI Area | Backend Component |
| --- | --- |
| Header | Header / Menu |
| Hero | Hero or HeroSlider |
| Services cards | ServiceGrid or CardGrid |
| Partner strip | LogoSlider or PartnerGrid |
| Mission/Vision | CardGrid or ImageText |
| Core values | FeatureGrid |
| Leadership | TeamGrid |
| Careers hero | Hero |
| Job filters | JobList |
| Open roles | JobList |

| Contact details | ContactInfo |
