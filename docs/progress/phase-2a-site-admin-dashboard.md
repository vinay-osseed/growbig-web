# Phase 2A: Site Admin Dashboard

## Purpose

Add a simple content admin dashboard for the reusable site platform.

## Scope completed

Created custom module:

- site_platform_admin

Added admin route:

- /admin/site-dashboard

Added dashboard cards:

Ready:

- Site Settings
- Menus
- Content
- Media Library
- API Docs

Planned:

- Pages
- Services
- Partners
- Leadership

## Access

The dashboard currently uses Drupal's content overview permission.

## Notes

Careers, contact forms, and analytics remain on hold.

The dashboard is intentionally simple in this phase. It provides a clean starting point for content admins and will be expanded as new platform content models are added.

## Next phase

Phase 3 will add the reusable Page content type and section paragraph model.
