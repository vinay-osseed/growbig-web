# Phase 10A: Role-Based Admin Access

## Purpose

Add flexible backend roles for admin access management.

## Roles Added

- site_developer
- content_admin
- hr_manager
- form_manager
- analytics_viewer

## Role Intent

### Site Developer

Developer/super-admin role for configuration and platform management.

### Content Admin

Manages content, pages, media, reusable content, jobs, and page menu fields.

### HR Manager

Manages jobs and job application submissions.

### Form Manager

Manages contact and Webform submissions.

### Analytics Viewer

Reserved for analytics/reporting dashboard access.

## Notes

Permissions are granted only when available in the current Drupal install.

This keeps the setup flexible across fresh installs and future module changes.
