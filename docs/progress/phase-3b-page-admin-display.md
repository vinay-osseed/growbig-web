Improve the Drupal admin editing experience for the reusable Site Page content model and section paragraph types.

Configured form displays for:

- Site Page
- Hero Section
- CTA Section
- Stats Section

- Card Grid Section
- Card Item
- Image Text Section
- Content List Section

Configured default view displays for the same entities.

Updated Site Dashboard:

- Pages card changed from Coming Soon to Ready
- Pages card now links to the Site Page content list
