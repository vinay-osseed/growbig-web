# Phase 4A: Business Content Model

## Purpose

Add reusable business content types that can power frontend sections and dynamic content lists.

## Scope completed

Created content types:

- Service
- Partner
- Team Member

## Service fields

- Service Key
- Sites
- Summary
- Icon
- Accent Color
- Image
- Link URL
- Display Order
- Is Featured
- Is Active
- Meta Title
- Meta Description

## Partner fields

- Partner Key
- Sites
- Summary
- Logo
- Website
- Display Order
- Is Featured
- Is Active

## Team Member fields

- Member Key
- Sites
- Role
- Summary
- Bio
- Photo
- Email
- LinkedIn URL
- Display Order
- Is Featured
- Is Active

## Notes

These content types are reusable across sites.

The Sites field controls which Site Profile each item belongs to.

Dynamic API population for Content List sections will be handled in the next phase.
